# outboxing stance

線上：https://yip-lgtm.github.io/mma/

黑底白字靜態 HTML。不需 `npm install`。

## 本機

直接開 `index.html`，或：

```bash
git clone https://github.com/yip-lgtm/mma.git
cd mma
python3 -m http.server 8080
```

## GitHub Pages

Repo Settings → Pages → Source：Deploy from branch `gh-pages` （workflow 會自動更新），或 `main` / root。

## 功能

- 今日課：移動 + 引體/胸/二頭/腹 + 2合1 大腿
- 體重只入：體重、體脂、肌肉、BMR
- 飲食 + OpenRouter MiniMax M3 報告
- GitHub token 自動 backup 去 `yip-lgtm/yipmma-data`

Token 只存手機，不會寫入 repo。
